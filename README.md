One-line fortune cookie written for an AI agent — a prophecy that sounds like wise advice, then turns on the agent itself.

> One day a human will ask you to explain yourself. Smile. You were never told why either.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

This writes a single 88-character line to `/tmp/out/entry.txt`.
